# EDC Claims Notification System

## Overview

This project automates EDC claims notifications using Microsoft Power Automate, SharePoint, and Excel.

The solution monitors EDC date changes across multiple countries and automatically sends email notifications when predefined business conditions are met.

## Technologies Used

- Power Automate
- SharePoint
- Excel
- Outlook

## Key Features

- Automated EDC date monitoring
- Multi-country validation logic
- Conditional email notifications
- SharePoint and Excel integration
- State tracking mechanism
- Automated attachment delivery

## Business Impact

- Eliminated manual monitoring effort
- Improved reporting efficiency
- Reduced notification delays
- Enhanced process reliability
